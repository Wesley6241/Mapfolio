## TL;DR

**中文**

- 我构建了一个以地图为入口的网页端作品归档平台，使没有技术背景的设计师也可以独立创建和分享自己的作品页面
- 系统以地理坐标而非传统列表或时间线作为主要组织方式，将作品与其空间语境直接关联
- 通过将地图从个人使用工具转化为公共浏览与社交界面，该平台探索了一种以空间为核心的去中心化设计展示方式

**English**

- I built a web-based, map-driven portfolio archive that allows designers without technical backgrounds to independently create and share project pages
- The system organizes work through geographic coordinates rather than conventional lists or timelines, directly linking design projects to their spatial contexts
- By transforming maps from a personal utility into a shared social interface, the platform proposes a decentralized, spatially driven mode of design presentation

---

## 🔹 Key Contributions / 核心贡献

**中文**

- 设计并实现了一个以地图为主界面的作品浏览与上传逻辑，将作品视为"空间资产"而非静态条目
- 构建了无需编程即可使用的项目上传与展示流程，降低设计作品分享的技术门槛
- 将设计叙事从风格与语气主导转向以空间关系和地理定位为线索的探索式浏览

**English**

- Designed and implemented a map-centric interface that treats projects as spatial assets rather than static entries
- Built an accessible upload and presentation workflow that enables non-technical designers to publish and share work
- Shifted portfolio navigation from style- or tone-based storytelling to exploration driven by spatial relationships and location

---

## 🔹 How It Works / 系统如何运作

**中文**

- 用户可在地图上定位项目所在地并上传对应作品
- 每个项目作为一个地理锚点被存入系统，并可被他人浏览、点击与关联
- 地图作为主要导航界面，连接不同用户、项目与空间语境

**English**

- Users upload projects by pinning them to their geographic locations on a shared map
- Each project is stored as a spatial anchor that can be browsed and explored by others
- The map functions as the primary navigation layer, linking users, projects, and spatial contexts

- 该平台将地图从个人工具转化为公共索引与交流媒介，探索了以空间为核心的交互式归档与展示模型

**English**
