About MapFolio

What is MapFolio?

MapFolio is an interactive mapping platform that allows users to create and share location-based projects. Each project is represented by a pin on the map, containing images, descriptions, and location data.

Manual

1) Add a New Project (Pin)

  • Right-click on the map where you want to place your project and choose Add Pin.
  • Fill in the form: Project Type, Title, Year, Full Credit, Description.
  • Set a 4-digit PIN (needed for future edits/deletion).
  • Upload a Thumbnail (≥ 800×600). Optionally upload a gallery.
  • Click Save and Continue to create your project.

2) View Projects

  • Click any pin to open its popup, then choose View for details.
  • Use List-view Archive to browse all projects with thumbnails.

3) Edit / Delete with PIN

  • Right-click near an existing pin and choose Edit Existing Pin, enter your 4-digit PIN to unlock editing.
  • To delete a project, choose Delete in the same PIN flow (you must enter the correct PIN).

4) Navigation Controls

  • Navigate toggles whether the map accepts drag/zoom.
  • Add Location opens the upload form without clicking the map.

5) Image & Storage

  • Large images are optimized on upload; gallery images preserve order.
  • All data is saved locally on this server (SQLite + local images).

6) Privacy & Security

  • Your 4-digit PIN protects edits/deletion of your own project.
  • No personal data is collected beyond what you enter in the form.
